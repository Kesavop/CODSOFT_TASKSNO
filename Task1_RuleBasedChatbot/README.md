# Kesav Chatbot 🤖

A simple rule-based AI chatbot developed using Python as part of the CodSoft Artificial Intelligence Internship.

## 📌 Task

Task 1 - Chatbot with Rule-Based Responses

## 🧠 About the Project

Kesav Chatbot is a rule-based chatbot that responds to user inputs using predefined patterns and conditional statements.

The chatbot can:

- Respond to greetings
- Introduce itself
- Answer basic questions about AI
- Explain Python and programming
- Provide the current date
- Provide the current time
- Respond to simple conversations
- Handle unknown questions
- Exit the conversation when requested

## 🛠️ Technologies Used

- Python 3
- Regular Expressions
- DateTime module

## ⚙️ How It Works

The chatbot converts the user's input to lowercase and checks it against predefined patterns.

For example:

- If the user says "hello", the chatbot returns a greeting.
- If the user asks about AI, it provides a predefined explanation.
- If the user asks for the time, it returns the current system time.
- If the user says "bye", the chatbot ends the conversation.
