**Technologies:**

---

### Task 2 - Tic-Tac-Toe AI

A classic Tic-Tac-Toe game where a human player competes against an AI opponent.

The AI uses the **Minimax algorithm with Alpha-Beta Pruning** to evaluate possible moves and play optimally.

**Folder:** `Task2_TicTacToeAI/`

**Technologies:**
- React
- TypeScript
- Vite
- CSS
- Minimax
- Alpha-Beta Pruning

**Features:**
- Human vs AI gameplay
- Unbeatable AI
- Win and draw detection
- Move validation
- New game functionality
- Automated tests
